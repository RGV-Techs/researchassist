\section{Abstract}
% ============================================================

The Autonomous Research Assistant is a web-based application designed to automate the discovery, summarization, and citation management of academic research papers. By leveraging the Semantic Scholar API (200M+ papers) and Google Gemini 2.5 Flash for natural language processing, the system enables researchers to efficiently locate relevant literature, obtain concise AI-generated summaries, extract key terminology, and generate properly formatted citations in APA, MLA, and IEEE styles. A supervised machine learning classification pipeline trained on 18,000 arXiv paper abstracts across six research domains was evaluated over five classifiers; the best-performing model, a tuned \textbf{Linear SVM}, achieves \textbf{97.25\% test accuracy} and a macro F1-score of 0.97. This report presents the motivation, methodology, architecture, dataset, model training results, and current progress of the project.

% ============================================================
\section{Introduction}
% ============================================================

The volume of academic publications has grown exponentially over the past two decades. Researchers across all disciplines face the challenge of identifying, reading, and organizing an ever-increasing body of literature. Traditional manual literature review is time-consuming, error-prone, and often results in incomplete coverage of relevant work.

There is a clear need for intelligent tools that can assist researchers in navigating large corpora of publications. The Autonomous Research Assistant addresses this need by providing a unified platform where users can search for papers, receive machine-generated summaries, and manage citations—all within a single interface. Additionally, a text classification module automatically categorizes discovered papers into six distinct research domains.

% ============================================================
\section{Problem Statement}
% ============================================================

Researchers routinely spend a significant portion of their time on literature review activities such as searching for papers, reading lengthy abstracts, extracting key concepts, and formatting citations in various styles. These tasks are repetitive and do not require deep intellectual engagement, yet they consume considerable effort. Furthermore, manually maintaining consistency across citation formats (APA, MLA, IEEE) is a frequent source of errors. The lack of an integrated, automated solution for these tasks motivates the development of the Autonomous Research Assistant.

% ============================================================
\section{Objectives}
% ============================================================

The primary objectives of this project are:

\begin{itemize}[leftmargin=1.5cm]
  \item To build a web application that enables automated discovery of research papers from large academic databases (200M+ papers via Semantic Scholar).
  \item To implement AI-powered text summarization using Google Gemini 2.5 Flash that condenses paper abstracts into concise 2--3 sentence summaries.
  \item To extract 5--7 domain-specific key technical terms and keywords from each research paper automatically.
  \item To generate citations in multiple standard formats (APA 7th, MLA 9th, IEEE) without manual effort.
  \item To train and compare five supervised machine learning classifiers on the arXiv dataset, achieving over 97\% test accuracy.
  \item To provide project-based organization so that users can manage literature for multiple research topics simultaneously.
  \item To enable export of citations and generation of PowerPoint presentation slides for academic reporting.
\end{itemize}

\subsection{Paper Discovery Pipeline}

The core pipeline, shown in Figure~\ref{fig:dataflow}, is implemented as a Deno-based Edge Function:

\begin{enumerate}[leftmargin=1.5cm]
  \item User submits a search query through the React frontend.
  \item The Edge Function queries the Semantic Scholar API with retry logic (3 attempts, exponential backoff: 2s, 4s).
  \item On API unavailability, Gemini 2.5 Flash generates realistic paper metadata as a fallback.
  \item Each abstract is summarized to 2--3 sentences and 5--7 keywords are extracted via Gemini.
  \item Papers are classified into one of six domains using a Gemini prompt encoding the trained SVM taxonomy.
  \item APA, MLA, and IEEE citations are auto-generated from structured metadata.
  \item All enriched data is stored in PostgreSQL with user-scoped RLS policies.
\end{enumerate}

\section{Dataset}
% ============================================================

The classification module is trained on the \textbf{arXiv Paper Abstracts} dataset from Cornell University via Kaggle\footnote{\url{https://www.kaggle.com/datasets/Cornell-University/arxiv}}. The full dataset contains metadata for over 1.7 million research papers; it is released under the CC0 (Public Domain) license.

\subsection{Data Sampling and Categories}

To maximize inter-domain separability and minimize classification ambiguity, six non-overlapping research domains were selected:

Papers with abstracts shorter than 30 words were excluded to ensure sufficient textual content for feature extraction. The dataset was split 80/20 stratified: 14,400 training samples and 3,600 test samples.

\subsection{Data Preprocessing}

The preprocessing pipeline consists of the following steps:

\begin{enumerate}[leftmargin=1.5cm]
  \item \textbf{Lowercasing:} All text converted to lowercase.
  \item \textbf{Special Character Removal:} Non-alphabetic characters removed (hyphens preserved for compound terms).
  \item \textbf{Tokenization:} NLTK word tokenizer.
  \item \textbf{Stopword Removal:} Standard English stopwords plus 24 domain-generic academic terms (``paper'', ``propose'', ``method'', etc.).
  \item \textbf{Lemmatization:} WordNet-based lemmatization to normalize morphological variants.
  \item \textbf{Token Filtering:} Tokens shorter than 3 characters discarded.
  \item \textbf{Title Weighting:} Paper titles are cleaned and repeated twice, then prepended to the abstract to amplify title signal in the feature representation.
\end{enumerate}

\section{Model Training and Results}
% ============================================================

Five supervised classifiers were trained and evaluated using stratified 5-fold cross-validation on the 80/20 train-test split.

\subsection{Classifier Descriptions}

\begin{enumerate}[leftmargin=1.5cm]
  \item \textbf{Logistic Regression:} L2-regularized, $C=5.0$, \texttt{lbfgs} solver, 2000 iterations, multinomial.
  \item \textbf{Multinomial Naive Bayes:} Laplace smoothing $\alpha=0.01$.
  \item \textbf{Linear SVM (Tuned):} \texttt{LinearSVC} with $C=1.0$, 5000 iterations, wrapped in \texttt{CalibratedClassifierCV} (3-fold, Platt scaling).
  \item \textbf{SGD Classifier:} Modified Huber loss, $\alpha=10^{-5}$, L2 penalty, 2000 iterations.
  \item \textbf{Random Forest:} 500 estimators, no depth constraint.
\end{enumerate}

\subsection{Production Deployment}

The trained classifier's domain taxonomy is integrated into the production application via a \textbf{prompt-engineering approach}: the Edge Function invokes Gemini 2.5 Flash with a classification prompt encoding the six-domain taxonomy derived from the trained SVM. This avoids the need to run a Python runtime in the Deno serverless environment while leveraging the ML model's validated knowledge.

\section{Conclusion}
% ============================================================

The Autonomous Research Assistant demonstrates a practical integration of modern web technologies, large language models, and supervised machine learning to address a real challenge faced by academic researchers. The system automates paper discovery from a 200M+ paper corpus, generates AI-powered summaries and keyword extractions, classifies papers into research domains, and formats citations in three standard styles.

The ML classification module was rigorously evaluated across five classifiers trained on 18,000 arXiv paper abstracts. The tuned Linear SVM emerged as the best model with \textbf{97.25\% test accuracy} and a macro F1-score of 0.97, outperforming Logistic Regression (97.06\%), SGD Classifier (97.03\%), Multinomial Naive Bayes (96.69\%), and Random Forest (94.44\%). The model's six-domain taxonomy is successfully deployed in the production Edge Function through prompt engineering with Gemini 2.5 Flash.

The project successfully integrates a React 18 frontend, Deno serverless backend, PostgreSQL database with RLS, and external AI services into a cohesive, secure platform. Future work will focus on transformer-based classification, expanded data sources, and collaborative features.
